Swipey's Edit AI help describes changes to a private Custom AI's look, name, voice and certain scenario details. It says personality remains fixed and Community-published Custom AIs cannot be edited. Read the current option on your own profile before deciding how to make a revision.

## Plan one observable change

Imagine an adult fictional ferry supervisor wearing a dark coat. If all you want is a new coat color, choose only the relevant appearance change. If you want her to handle problems with a different personality, check the separate creation option described by the provider. Keep the old character's role and scene notes available.

## Read the effect of saving

Check the current Hearts cost and whether regeneration is still in progress. Review the resulting appearance when the interface shows it is ready. Confirm the audience of any new character before making it available to others.
